# EasyLine — 2.3.0-preview

Ветка `codex/menu-refresh-2026-10-17` основана на проверенном 17 октября 2026 сайте [easyline.club](https://easyline.club/). Публичный сайт продолжает использовать ветку `version-2.2.3`. Этот вариант не опубликован.

Главная представляет три направления: протокол на 28 дней, 13 корпоративных обедов и ассортимент из 26 позиций. Новые каталоги имеют поиск, категории, фильтры начинки и цельнозернового хлеба. Общая корзина сохраняет только ID блюд и количество, поддерживает изменение количества и синхронизацию между вкладками.

**Цены, новые фотографии, условия доставки и оплаты ещё не предоставлены.** Они не выдуманы. Корзина и экран оформления доступны для просмотра; отправка нового заказа и оплата отключены. Протокол сохраняет существующую отдельную заявку в EasyLine ERP. Реальные заявки при проверке не отправлялись.

## Исходники

- `src/page.html` — оболочка и сохранённые страницы протокола, производства, доставки, контактов и документов.
- `src/home.html`, `src/catalogs.html`, `src/cart-pages.html` — новые страницы.
- `src/product-card.html`, `src/quantity.html` — общие элементы.
- `src/site-logic.js`, `src/retained-content.js` — поведение и сохранённый контент.
- `src/catalog.json` — 39 позиций. `priceRub` и `image` пока равны `null`.
- `src/cart.js` — фильтры, проверка корзины, хранение и расчёт известной стоимости.
- `assets/menu-refresh.css` — стили новых элементов на основе текущей палитры и шрифтов.

`index.html`, HTML маршрутов, sitemap, runtime метаданных и модуль `assets/menu-catalog-<hash>.js` генерируются. Их не редактируют вручную. Новые изображения назначают только после сопоставления с предоставленными фото.

## Сборка и проверка

```bash
node scripts/sync-static-site.mjs
node scripts/verify-static-site.mjs
node --test tests/*.test.mjs
```

Требуется Node.js 18+. Перед подключением оформления нужны подтверждённые цены, наличие, условия доставки и оплаты, а также интеграция приёма заказов. Юридические документы сохранены; перед публикацией новых направлений нужно проверить их применимость к новому способу заказа.
