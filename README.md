# EasyLine — версия 2.2.3

Версия 2.2.3 на основе опубликованной версии 2.2.2: сохранена компактная шапка, добавлены проверяемые метаданные для всех маршрутов, sitemap и улучшенная мобильная читабельность.

Публичный сайт: https://moseskm98-code.github.io/easyline-site/

- Основа: локальный handoff-пакет `design_handoff_easyline_site`
- Дата обновления публикации: 30 августа 2026 года
- Фотографии блюд и производства являются сгенерированными визуализациями для прототипа.

Публикация сохраняет отдельный слой увеличенной типографики и принудительно светлое оформление для мобильных браузеров. Белая оболочка сайта следует реальной ширине окна и не оставляет голубую полосу справа на больших телефонах и широких экранах.

## Ветка исправленной версии

Версия хранится в ветке `version-2.2.3`, созданной от `main`. GitHub Pages продолжает публиковаться из `main`, поэтому одна только эта ветка не меняет действующий сайт.

Контроль после развёртывания:

- в HTML установлен маркер `window.__EASYLINE_VARIANT__ = "2.2.3"`;
- `frameMax` равен `100vw`;
- на ширине 440 px правая граница `.el-site-shell` совпадает с правой границей окна.

По решению владельца в версии сохранены демонстрационный ИНН `057200000000` и заглушка карты `карта проезда · 16:9`.

## Локальная проверка

Проверка статического GitHub Pages-артефакта:

```bash
node scripts/verify-static-site.mjs
```

Требуется Node.js 18+.

После публикации sitemap `https://moseskm98-code.github.io/easyline-site/sitemap.xml` нужно вручную отправить в Google Search Console и Bing Webmaster.

Этим project repo нельзя управлять effective `robots.txt` на host root: для этого нужен `https://moseskm98-code.github.io/robots.txt`, который находится вне области управления `easyline-site`.
