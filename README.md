# EasyLine 2.6.5

Главная с полным меню. Публикация через существующий GitHub Pages: ветка `version-2.2.3`, путь `/`. Релиз также обновляет `main`.

- Просмотр: http://127.0.0.1:4194/
- Вариант с постоянными двумя строками: http://127.0.0.1:4196/
- Предыдущая версия 2.5: http://127.0.0.1:4191/
- Действующая версия 2.4.9 сохранена отдельно: http://127.0.0.1:4192/

Четыре формата представлены карточками с фото. На телефоне карточки листаются горизонтально. На большом экране видны все четыре.

Все 39 блюд доступны на главной: 13 обедов, 3 боула, 23 позиции ПП-фастфуда в пяти подкатегориях. Основная строка содержит обеды, боулы и ПП-фастфуд. Строка закрепляется под шапкой. Подкатегории ПП-фастфуда сначала идут под заголовком раздела, затем естественно закрепляются под основной строкой. При возврате к боулам или обедам вторая строка уходит вместе со своим разделом.

Поведение сверено с исходной записью приложения Додо (30,13 с): переходы 8,8–9,0 с, 15,0–15,2 с и 23,8–24,0 с. Фон активной категории меняется за 180 мс; горизонтальная строка плавно перемещается к ней. Ссылки прокручивают страницу за 260–440 мс. При reduced motion переход мгновенный, переходы цвета отключены.

Общая корзина доступна на главной. Возврат из корзины сохраняет раздел и положение прокрутки. Панель блюда, прямой ввод числа порций и подписи предварительных фото сохранены. Рацион на 28 дней использует отдельную заявку. Цены и составы не добавлены. Оформление нового меню по-прежнему отключено.

В независимой проверке исправлены потеря фокуса после добавления блюда, сброс места возврата после обновления корзины, восстановление прокрутки до загрузки меню и дублирование мобильного меню при расширении окна. Ссылки каталогов ведут сразу на адреса с завершающим `/`, без перенаправления. В историю браузера попадают только параметры каталога и позиция прокрутки; корзина в localStorage содержит только ID и количество.

Исходники — в src/. Стили и поведение главной — assets/home-menu.css и assets/home-menu.js. HTML маршрутов генерируется:

```
node scripts/sync-static-site.mjs
node scripts/verify-static-site.mjs
node --test tests/*.test.mjs
```
